## 開発プロキシ設定

フロントエンド開発時、すべての `/api/*` リクエストは自動的にバックエンドにプロキシされます（クロスオリジンを回避）：

%%CODEBLOCK_6%%**GitHub OAuth ログインフロー**：

1. ユーザーが「GitHubでログイン」をクリックすると、フロントエンドは直接 `/api/auth/github` にリダイレクトされます（バックエンドがGitHubにリダイレクト）
2. GitHub認証後、コールバックは `/api/auth/github/callback` です
3. バックエンドの処理後、フロントエンドの `/dashboard?token=xxx` または `/setup?token=xxx` にリダイレクトされます
4. `App.vue` 内で URL の `token` パラメータを自動的に抽出し、`localStorage` に保存します
5. その後のすべての API リクエストに自動的に `Authorization: Bearer {token}` ヘッダーが追加されます

## よくある質問

### Q: ページが真っ白/空白になる

- npm install が完了していることを確認してください
- Node.js のバージョン ≥ 20 を確認してください- ブラウザーコンソールのエラーを確認してください

### Q: API リクエストが 404 / ネットワークエラー- バックエンドの Spring Boot サービスがポート 8080 で実行されていることを確認してください
- vite.config.ts のプロキシ設定を確認してください

### Q: ログイン後に /setup へリダイレクトされ、/dashboard へいかない

- これは GitHub App がまだインストールされていないことを示しています。インストールガイドの手順に従ってインストールを完了してください

### Q: 翻訳設定ページのファイルツリーが空

- リポジトリがプラットフォームに追加されていることを確認してください
- GitHub App がそのリポジトリにアクセス権限を持っていることを確認してください
- バックエンドインターフェース GET /api/repos/{id}/tree が正常にデータを返す必要があります

### Q: バックエンド API アドレスをどのように切り替えますか

`vite.config.ts` の proxy target を変更するか、本番環境で Nginx のリバースプロキシ設定を行います。
