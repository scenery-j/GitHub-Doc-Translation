## 開発プロキシ設定

フロントエンド開発時、すべての `/api/*` リクエストは自動的にバックエンドにプロキシされます（クロスオリジンを回避）：

%%CODEBLOCK_6%%

**GitHub OAuth ログインフロー**：

1. ユーザーが「GitHubでログイン」をクリック → フロントエンドが直接 `/api/auth/github` にリダイレクト（バックエンドがGitHubにリダイレクト）
2. GitHubの認証後にコールバック `/api/auth/github/callback`
3. バックエンドの処理後にフロントエンドの `/dashboard?token=xxx` または `/setup?token=xxx` にリダイレクト
4. `App.vue` 内でURLの `token` パラメータを自動抽出し、 `localStorage` に保存
5. すべての後続のAPIリクエストに自動的に `Authorization: Bearer {token}` ヘッダーが追加されます

## よくある質問

### Q: ページが真っ白/空白になる

- npm install が完了していることを確認してください
- Node.js のバージョンが 20 以上であることを確認してください
- ブラウザのコンソールエラーを確認してください

### Q: API リクエストが 404 / ネットワークエラー

- バックエンドの Spring Boot サービスがポート 8080 で実行されていることを確認してください
- vite.config.ts のプロキシ設定を確認してください

### Q: ログイン後に /setup へリダイレクトされ、/dashboard へいかない

- GitHub App がまだインストールされていないことを示します。インストールガイドの手順に従ってインストールを完了してください。

### Q: 翻訳設定ページのファイルツリーが空

- リポジトリがプラットフォームに追加されていることを確認してください
- GitHub App がそのリポジトリにアクセス権限を持っていることを確認してください
- バックエンドエンドポイント GET /api/repos/{id}/tree が正常にデータを返す必要があります

### Q: バックエンド API アドレスをどのように切り替えますか

`vite.config.ts` の proxy target を変更するか、本番環境で Nginx のリバースプロキシ設定を行ってください。
