# 快速启动指南

> **前提**：已完成《人工配置文档》中的所有配置步骤。

---

## 环境要求

| 工具 | 版本 |
|------|-----|
| Java | 21 (LTS) |
| Maven | 3.9+ |
| Docker + Docker Compose | 任意新版 |
| Node.js（可选，Smee 转发） | 18+ |

---

## 第一步：克隆并进入后端目录

```bash
cd doc_translation_service
```

---

## 第二步：配置环境变量

```bash
# 复制示例配置文件
cp .env.example .env

# 编辑 .env 文件，填入所有必要配置
vim .env   # 或用你喜欢的编辑器
```

**必须填写的配置项：**

```bash
# GitHub App 信息（从 GitHub App 设置页获取）
GITHUB_APP_ID=123456
GITHUB_APP_CLIENT_ID=Iv1.xxxxxxxxxxxxxxxx
GITHUB_APP_CLIENT_SECRET=xxxxxxxxxxxxxxxxxxxx
GITHUB_APP_WEBHOOK_SECRET=your-webhook-secret

# 私钥文件路径（下载的 .pem 文件）
GITHUB_APP_PRIVATE_KEY_PATH=./github-app-private-key.pem

# OpenRouter API Key
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxx

# 安全密钥（必须修改！）
JWT_SECRET=your-random-jwt-secret-32chars-here
ENCRYPTION_KEY=your-32-char-encryption-key!!!!
```

---

## 第三步：将 GitHub App 私钥放到项目目录

```bash
# 将从 GitHub 下载的 .pem 私钥文件复制到后端目录
cp ~/Downloads/your-app-name.YYYY-MM-DD.private-key.pem \
   doc_translation_service/github-app-private-key.pem
```

---

## 第四步：启动基础设施（PostgreSQL + Redis）

```bash
cd doc_translation_service

# 启动 PostgreSQL 和 Redis（后台运行）
docker-compose -f docker-compose.dev.yml up -d

# 验证服务已启动
docker-compose -f docker-compose.dev.yml ps
```

预期输出：
```
NAME                          STATUS
doc_translation_postgres      running (healthy)
doc_translation_redis         running (healthy)
```

---

## 第五步：启动后端服务

### 方式一：Maven 直接运行（推荐开发）

```bash
cd doc_translation_service

# 加载 .env 文件后运行（macOS/Linux）
export $(cat .env | grep -v ^# | xargs) && mvn spring-boot:run

# 或直接运行（需要预先 export 环境变量）
mvn spring-boot:run
```

### 方式二：编译为 JAR 运行

```bash
cd doc_translation_service

# 编译打包
mvn package -DskipTests

# 运行（先加载 .env）
export $(cat .env | grep -v ^# | xargs)
java -jar target/doc-translation-service-1.0.0-SNAPSHOT.jar
```

---

## 第六步：验证启动成功

```bash
# 检查健康状态
curl http://localhost:8080/actuator/health

# 期望输出：
# {"status":"UP"}

# 测试 API（需要 JWT Token）
curl http://localhost:8080/api/auth/github
# 期望：重定向到 GitHub OAuth 页面（302）
```

**启动日志中应出现：**
```
Started DocTranslationApplication in X.XXX seconds
Flyway: Successfully applied 1 migration to schema "public"
```

---

## 第七步：启动 Webhook 本地转发

> 此步骤仅本地开发时需要，生产环境跳过。

```bash
# 安装 smee-client（仅需安装一次）
npm install -g smee-client

# 启动转发（替换为你的 Smee URL）
smee --url https://smee.io/your-channel-id \
     --path /api/webhook/github \
     --port 8080
```

保持此终端运行，GitHub 的 Webhook 事件将被转发到本地。

## 常见问题排查

### 问题：启动失败，提示 "Failed to configure a DataSource"

**原因**：PostgreSQL 未启动或连接信息错误

**解决**：
```bash
# 检查容器状态
docker ps | grep postgres
# 检查连接
docker exec doc_translation_postgres pg_isready -U dev -d doc_translation
```

---

### 问题：启动时报 "Could not load private key"

**原因**：私钥文件路径错误或文件不存在

**解决**：
```bash
# 确认私钥文件存在
ls -la doc_translation_service/github-app-private-key.pem

# 确认 .env 中路径正确
# GITHUB_APP_PRIVATE_KEY_PATH=./github-app-private-key.pem
```

---

### 问题：OAuth 回调后 JWT 无效

**原因**：`JWT_SECRET` 未配置或不足 32 字符

**解决**：更新 `.env` 中的 `JWT_SECRET` 为至少 32 字符的随机字符串。

---

### 问题：翻译任务失败，提示 "AI翻译API调用失败"

**原因**：`OPENROUTER_API_KEY` 未配置或余额不足

**解决**：
1. 检查 API Key 是否正确配置
2. 访问 [https://openrouter.ai/](https://openrouter.ai/) 检查账户余额
3. 也可在系统设置中配置自己的 API Key

## 停止服务

```bash
# 停止后端（Ctrl+C 或）
kill $(lsof -ti:8080)

# 停止数据库和缓存
cd doc_translation_service
docker-compose -f docker-compose.dev.yml down

# 如需清除数据
docker-compose -f docker-compose.dev.yml down -v
```
