# 人工配置文档

> 本文档说明运行项目前需要手动完成的所有配置步骤。

---

## 一、注册 GitHub App

### 1.1 创建 GitHub App

1. 登录 GitHub → Settings → Developer settings → **GitHub Apps** → **New GitHub App**

2. 填写以下信息：

本地smee地址：https://smee.io/1oroSknpG6ZUVE7O

| 字段 | 值                                                            |
|------|--------------------------------------------------------------|
| GitHub App name | `github-doc-translation`（全局唯一名称）                             |
| Homepage URL | `http://localhost:5173`（开发环境）                                |
| Callback URL | `http://localhost:8080/api/auth/github/callback`             |
| Setup URL (optional) | 留空                                                           |
| Webhook URL | `https://your-smee-url.smee.io/api/webhook/github`（开发用 Smee） |
| Webhook secret | 随机生成一个安全字符串，记录备用 - scenery_doc_translation                          |

3. **Permissions** 设置：

| 权限类型 | 权限级别 |
|---------|---------|
| Contents | Read & Write |
| Pull requests | Read & Write |
| Metadata | Read-only |

4. **Subscribe to events**（勾选）：
   - `push`
   - `pull_request`
   - `installation`
   - `installation_repositories`

5. **Where can this GitHub App be installed?** → 选择 `Any account`

6. 点击 **Create GitHub App**

### 1.2 获取配置信息

创建完成后，记录以下信息到 `.env` 文件：

```bash
GITHUB_APP_ID=<App ID，在 App 设置页顶部显示>
GITHUB_APP_CLIENT_ID=<Client ID，在 App 设置页显示>
GITHUB_APP_CLIENT_SECRET=<点击 "Generate a new client secret" 生成>
GITHUB_APP_WEBHOOK_SECRET=<上一步填写的 Webhook Secret>
```

### 1.3 下载私钥

在 GitHub App 设置页面 → **Private keys** → **Generate a private key**

下载的 `.pem` 文件放置在以下位置：
```bash
doc_translation_service/github-app-private-key.pem
```

并配置：
```bash
GITHUB_APP_PRIVATE_KEY_PATH=./github-app-private-key.pem
```

## 二、获取 OpenRouter API Key

> 可以配置平台级 API Key（所有用户共享额度），用户也可在系统内配置自己的 Key。

1. 访问 [https://openrouter.ai/](https://openrouter.ai/)
2. 注册/登录 → 右上角头像 → **Keys** → **Create Key**
3. 填写 Key 名称 → **Create** → 复制保存

```bash
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxx
```

## 三、配置安全密钥（必须修改！）

以下两个密钥**必须修改为随机安全字符串**，不可使用默认值：

### JWT 签名密钥（至少 32 字符）
```bash
JWT_SECRET=your-random-secret-at-least-32-characters-long
```

### AES-256 加密密钥（**必须恰好 32 字符**）
```bash
ENCRYPTION_KEY=your-32-char-encryption-key-here!
```

> **安全提示**：可使用以下命令生成随机密钥：
> ```bash
> # 生成 JWT Secret
> openssl rand -base64 32
> # 生成 Encryption Key（32字符）
> openssl rand -hex 16
> ```

## 四、本地开发 Webhook 转发（Smee.io）

GitHub Webhook 需要公网可访问的 URL，本地开发使用 Smee.io 转发。

### 4.1 安装 Smee 客户端

```bash
npm install --global smee-client
```

### 4.2 获取 Smee Channel

1. 访问 [https://smee.io/](https://smee.io/)
2. 点击 **Start a new channel**
3. 复制生成的 URL（如 `https://smee.io/abc123xyz`）

### 4.3 更新 GitHub App Webhook URL

将 GitHub App 的 Webhook URL 改为上面的 Smee URL：
```
https://smee.io/abc123xyz
```

### 4.4 启动转发

```bash
smee --url https://smee.io/abc123xyz --path /api/webhook/github --port 8080
```

## 五、数据库初始化

项目使用 **Flyway** 自动管理数据库迁移，首次启动时会自动执行 `V1__init_schema.sql`。

确保 PostgreSQL 服务已启动，且数据库信息正确：

```bash
DATABASE_URL=jdbc:postgresql://localhost:5432/doc_translation
DATABASE_USERNAME=dev
DATABASE_PASSWORD=dev123
```

**使用 Docker 启动 PostgreSQL + Redis（推荐）：**
```bash
cd doc_translation_service
docker-compose -f docker-compose.dev.yml up -d
```

数据库和 Redis 会自动创建，无需手动建库。

## 六、前端 GitHub App 安装配置

用户登录后，需要在 GitHub 上安装 GitHub App 才能访问仓库。

安装 URL 格式：
```
https://github.com/apps/<your-app-name>/installations/new
```

将此 URL 配置到前端"引导安装"页面。
